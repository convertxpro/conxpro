## Execution Guidelines

1. **Step-by-Step Execution:** Execute prompts in numerical order (`01` $\rightarrow$ `10`).
2. **Client-Side Privacy:** Tools in Sub-prompts 02, 03, 04, 05, 06, and 07 run entirely in the user's browser.
3. **Worker Pipeline:** Ensure the Redis BullMQ worker (`npm run worker`) is active when testing sub-prompts 08, 09, and 10.
4. **Verification:** Run `npm run lint` and `npm run build` after completing each prompt to ensure zero regressions.
